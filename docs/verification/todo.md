## タスクで決まったこと

- 下のタブは 3 つ（健診予定・タスク・健診の記録）。タブには、完了していない「期限を過ぎた」と「今日」のタスクの数を出す（R-106）。
- 期限は、選んだときの日付をそのまま持つ。「次の健診まで」も、押したときの次の健診の日付を入れるだけで、あとで次の健診の日付を変えても期限は動かない（R-102、ADR 0012）。
- 完了は 2 段階。丸を押すと緑のチェックが付いてその場に残り、「チェックした n 件を完了にする」で「完了したタスク」に移る（R-104）。聞きたいことの「丸を付ける → 健診後メモの保存で移る」と同じ考え方。
- 削除は左スワイプと「直す」の画面から。確認は出さず、元に戻すで戻せる（R-105）。
- 健診後メモからの追加は、メモの ID と受診日を持つ。関係でつながないので、メモを消してもタスクは残る（R-107、ADR 0012 の追記）。
- 「例から追加」（妊娠中によくあることの一覧）は入れない（R-108、開発者の判断）。期限の日のお知らせも最初の版には入れない。
- 画面での呼び名は「タスク」（2026-10-28、開発者の判断）。

## 気づいたこと（あとで扱う）

- 画面の出し分けを変えたら、画面のテストの手順も見直す（キーボードの「完了」の PR #43 で、入力中は保存の帯を隠すようにしたら、画面のテストが保存ボタンを見つけられなくなった）。
- 一覧の行の背景を透明にしても、中身は行の丸い角で切り取られる。行のはしに形のあるものを置くときは余白をとる（見出しの四角が欠けた、#41）。
