# 実機での動作確認（無料の個人チーム）

- 日付：2026-10-23
- 端末：iPhone 17 Pro、iOS 27.0.1
- 開発環境：Xcode 27。署名は無料の Apple Account（個人チーム）
- 使った画面：開発用ビルドだけにある「動作確認」画面（[DeviceCheckView.swift](../../PrenatalCheckupNote/DeveloperTools/DeviceCheckView.swift)）

## 目的

要件定義の「費用をかけない前提での確認」として、段階1・2で使う機能が、有料の Apple Developer Program なしで実機に入れて動くかを、画面を作り込む前に確かめます。あわせて、段階1の最初の技術検証 TV-04（共有シートからテキストを印刷できるか）を行います。

## 結果

| 項目 | 手順 | 結果 |
| --- | --- | --- |
| インストールと起動 | Xcode から実機に入れ、iPhone の設定で開発者を信頼してから起動する | できた |
| データの保存（SwiftData） | 確認用の記録を追加して保存し、アプリを完全に終了してから開き直す | 件数と日時が残っていた |
| ローカル通知 | 通知を許可し、10 秒後の通知を予約してホーム画面に戻る | 通知が表示された |
| 共有シート（A：標準） | SwiftUI の `ShareLink` に文章だけを渡す | 共有シートは開いたが、「プリント」は出なかった |
| 印刷の画面（B：直接） | `UIPrintInteractionController` に `UISimpleTextPrintFormatter` を渡して開く | 印刷の画面が開き、プレビューで文字が切れずに表示された |
| 共有シート（C：印刷つき） | `UIActivityViewController` に文章と `UISimpleTextPrintFormatter` を渡す | 「プリント」が出て、プレビューも正しく表示された。「メモ」に送った文章は二重にならず、崩れなかった |

## わかったこと

- 段階1・2で使う機能（SwiftData、ローカル通知、共有シート）は、無料の個人チームで実機に入れて動きます。
- 文章だけを共有シートに渡すと、印刷はできません。印刷用の項目も一緒に渡せば、1 つの共有シートで共有と印刷の両方を選べます。この結果をもとにした印刷の方針は [ADR 0004](../adr/0004-print-from-share-sheet.md) に記録しました。

## 確認していないこと

- iOS 26 での動作。共有シートの「プリント」だけは、段階1の共有プレビュー画面で、iOS 26.5 のシミュレーターでも出ることを確かめました（2026-10-23）。
- 紙に印刷したときの見え方。今回はプレビューまでを確認しました。
- 「メモ」以外の共有先（メッセージ、メールなど）での文章の扱い。
- アプリを開いているあいだの通知の表示。今回はホーム画面に戻った状態だけを確認しました。

## この画面の扱い

「動作確認」画面は Debug ビルドだけに含まれ、リリースビルドには入りません。Xcode や iOS を更新したときの再確認に使えるよう、段階1のあいだは残します。
