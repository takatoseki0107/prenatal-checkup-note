# ADR 0001: 最低対応 OS を iOS 26 にする

- 状態：採用
- 日付：2026-10-23

## 状況

Xcode 27 で作ったプロジェクトの既定の最低対応 OS は iOS 27 でした。開発者の実機（iPhone 17 Pro）は iOS 27 です。

## 決定

最低対応 OS を iOS 26 にします（`IPHONEOS_DEPLOYMENT_TARGET = 26.0`）。

## 理由

- **確認する範囲を絞るため。** 実機の iOS 27 と、シミュレーターの iOS 26 の 2 つを確認すれば済みます。iOS 18 まで広げると確認する版が 3 つになり、SwiftData の版による挙動の違いも確かめる必要が出ます。
- **使いたい API があるから、という理由ではありません。** `@Observable`、SwiftData、`#Unique` は iOS 18 以前から使えます。
- **SwiftData の安定性は、この時点の根拠にしません。** 段階2の技術検証（TV-01・TV-06 など）で確かめます。
- **利用者への影響は参考値として扱います。** Apple が 2026 年 6 月に公表した数値では、iOS 26 の利用率は iPhone 全体の 79% でした（[MacRumors, 2026-06-09](https://macrumors.com/2026/06/09/ios-26-adoption-stats-wwdc/)）。想定利用者だけの数値ではないため、影響が小さいとは断定しません。

## 影響

- 自動テスト（CI）で使えるのは iOS 27 のシミュレーターだけです。iOS 26 は手元のシミュレーターで確認し、確認した範囲を README に書きます。
- 利用者テストで古い OS の利用者が見つかり、技術検証で版による問題がなければ、iOS 18 への引き下げを考え直します。
